# 사진 촬영 위치 지도

`picture` 폴더에 있는 사진의 EXIF 정보(촬영 위치·시각·고도·촬영 방향·기기)를 읽어
Google 지도에 사진 마커와 촬영 방향 화살표로 보여 주는 웹앱입니다.

```
~/Project/DS_DB/picture/*.jpg ──EXIF──▶ app.py (Flask :5091) ──JSON──▶ 브라우저 (Google 지도)
                                  └ 썸네일·보기용 축소본은 cache/ 에 한 번만 생성 (원본은 그대로)
```

## 실행

```bash
cd ~/Project/DS_DB/photo_map
pip install -r requirements.txt      # flask, pillow, pillow-heif(아이폰 HEIC)
python app.py                        # → http://localhost:5091
```

터미널에 `[사진] … 15장 중 위치 있음 15장`, `[HEIC] pillow-heif`, `[지도] Google 지도`가 나오면 준비 완료입니다.
다른 폴더를 보려면 `PHOTO_DIR=~/Pictures/여행 python app.py`.

## Google 지도 키

제주 관광정보 탐색기와 **같은 키 `GOOGLE_MAPS_API_KEY`**를 씁니다
(환경변수 → `photo_map/.env` → `DS_DB/.env` → `tour_api/.env` 순으로 찾음).
단, Cloud 콘솔에서 키의 **웹사이트 제한에 `http://localhost:5091/*`를 추가**해야 합니다.
키가 없거나 인증에 실패하면 OpenStreetMap으로 자동 전환되고 화면 아래에 이유가 표시됩니다.

## 화면

| 영역 | 내용 |
| --- | --- |
| 왼쪽 목록 | 위치가 있는 사진(시간순)과 없는 사진. 누르면 크게 보기 + 지도 이동 |
| 지도 사진 | **모든 사진을 한 장씩** 썸네일로 표시. 현재 줌에서 화면상 겹치는 사진은 중심점 둘레에 둥글게 펼치고 흰 선으로 실제 위치를 가리킴. 확대하면 실제 위치로 나뉨. 누르면 크게 보기 |
| 상단 도구 | 사진 크기(작게/보통/크게), 촬영 방향, 이동 경로(날짜별 시간순 연결), 전체 보기 |
| 날짜별 목록 | 촬영일마다 묶어 보여 주고 "지도에서 보기"로 그날 사진만 확대 |
| 주황 화살표 | 촬영 방향(`GPSImgDirection`) — 카메라가 어느 쪽을 보고 찍었는지. 크게 보기 중인 사진은 파란색 |
| 크게 보기 | 촬영 시각(시간대), 좌표, 위치 정확도, 고도, 방향 나침반, 기기, 해상도, Google 지도 링크, ←/→ 키로 넘기기 |

지도는 기본으로 위성+지명(hybrid)으로 열리며 오른쪽 위에서 지도/위성을 바꿀 수 있습니다.

## 수업 포인트: EXIF에서 위치 꺼내기

EXIF의 GPS 값은 **도·분·초(DMS)** 로 저장되어 있어 십진수 도로 바꿔야 지도에 찍을 수 있습니다.

```
GPSLatitude  = (33, 21, 27.8), Ref 'N'  →  33 + 21/60 + 27.8/3600 = 33.35772
GPSLongitude = (126, 27, 45.03), Ref 'E' → 126.46251
```

남위(S)·서경(W)이면 음수가 됩니다 → `app.py`의 `_dms_to_deg()`.
세로로 찍은 사진은 `Orientation` 태그(6·8)를 반영해 돌려서 썸네일을 만듭니다(`ImageOps.exif_transpose`).

## 주의

- 카카오톡·메신저로 받은 사진, 스크린샷, 편집 앱에서 저장한 사진은 위치 정보가 지워져 있는 경우가 많습니다.
  아이폰은 **설정 → 개인정보 보호 → 위치 서비스 → 카메라**가 켜져 있어야 위치가 기록됩니다.
- 아이폰 기본 형식(HEIC)은 `pillow-heif`로 읽습니다. 설치가 안 돼 있으면 macOS 기본 도구 `sips`로 JPEG 사본을 만들어(cache/) 읽습니다.
- 사진의 위치 정보는 개인정보입니다. 이 앱은 내 컴퓨터(localhost)에서만 열리지만, 사진을 공유할 때는 위치 정보 포함 여부를 확인하세요.
